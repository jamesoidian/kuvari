## Overview

Kuvari is a Flutter-based assistive communication application designed for image- and symbol-based storytelling. It enables users to search for symbols and images from multiple sources (Papunet for Finnish and Swedish; OpenSymbols via Firebase Cloud Functions for English), assemble them into a sequential "story", play/view stories with text-to-speech audio narration in portrait or landscape mode, and manage saved stories with tags in local offline storage (Hive).

## Conventions

- **Architecture:** Layered approach (`pages/` -> `widgets/` -> `services/` -> `models/`).
- **Persistence:** Hive objects with generated type adapters (`*.g.dart`) via `hive_generator`.
- **State Management:** `StatefulWidget` with local `setState` for page state; `ValueListenableBuilder` listening to Hive box changes for reactive data updates.
- **Localization:** Flutter `AppLocalizations` generated from `.arb` files (`intl_fi.arb`, `intl_sv.arb`, `intl_en.arb`) with default locale `fi`.
- **Styling:** Unified palette centered on Teal (`Colors.teal`), with common tokens defined in `ThemeService`.
- **Testing:** Unit and widget tests in `test/` using `flutter_test`, `mockito`, `network_image_mock`, and `hive_test`. 42 passing test suites.
