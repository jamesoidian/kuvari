# Requirements: Kuvari — Milestone v1.6.0 Archive

**Milestone:** v1.6.0 — Story Editing & Safe Queue Management  
**Archived:** 2026-09-14  
**Core Value:** Providing a fast, simple, and intuitive visual communication tool that empowers users to express needs, understand daily structures, and make choices through symbols.

## Requirements Traceability

### Safe Story Carousel
- [x] **SAFE-01**: Disable drag reordering on `SavedImageStoriesPage` carousel (`isReorderable: false` / pure horizontal scroll) so viewing and swiping stories does not trigger accidental reorders.
  - *Outcome:* Validated in Phase 5 (`SelectedImagesCarousel` standard `ListView` mode).
- [x] **SAFE-02**: Ensure individual image delete buttons are absent in the saved stories carousel to prevent accidental deletion during browsing.
  - *Outcome:* Validated in Phase 5 (`showClearButton: false`, deletion overlay suppressed).

### Edit on Home Page Transition
- [x] **EDIT-01**: Provide an explicit "Muokkaa kotisivulla" (Edit on Home Page) button on each saved story card in `SavedImageStoriesPage`.
  - *Outcome:* Validated in Phase 6 (vertically stacked edit button alongside play button on each card).
- [x] **EDIT-02**: Show a confirmation warning dialog when opening a saved story for editing if the home queue already contains selected images.
  - *Outcome:* Validated in Phase 6 (warning dialog with active queue count and story title).
- [x] **EDIT-03**: Transition to `HomePage` in Edit Mode, populating the queue with the story's images and displaying a SnackBar confirming the story is open for editing.
  - *Outcome:* Validated in Phase 6 (route pop with story, HomePage state population, localized SnackBar).

### Home Page Edit Mode UI & Protection
- [x] **MODE-01**: Render a persistent Edit Mode banner above the collection queue on `HomePage` showing the story name and quick actions ("Tallenna muutokset" and "Lopeta muokkaus").
  - *Outcome:* Validated in Phase 6 (`EditModeBanner` in amber-50 container with edit name, save, and exit actions).
- [x] **MODE-02**: Guard against accidental data loss in Edit Mode by prompting confirmation when the user taps clear (trash can) or attempts to navigate away with unsaved modifications.
  - *Outcome:* Validated in Phase 6 (`PopScope` and queue clear confirmation dialogs).

### Dual-Mode Save Logic
- [x] **SAVE-01**: When saving in Edit Mode, present a dialog offering:
  1. "Päivitä olemassa oleva" (updates existing story in Hive, preserving ID and tags).
  2. "Tallenna uutena kuvajonona..." (prompts for a name, saves a new story with new ID).
  - *Outcome:* Validated in Phase 7 (`EditModeSaveDialog` two-step selection and name input).
- [x] **SAVE-02**: Cleanly exit Edit Mode upon saving or explicit cancellation, returning `HomePage` to its standard clean queue state.
  - *Outcome:* Validated in Phase 7 (state reset in `HomePage._saveImageStory` and cancel without modification loss).
