<task type="auto">
  <name>Task 1: Wire EditModeSaveDialog and Hive operations in HomePage</name>
  <files>
    lib/pages/home_page.dart
  </files>
  <action>
    1. In `lib/pages/home_page.dart`:
       - Add optional `final Box<ImageStory>? imageStoriesBox;` parameter to `HomePage` constructor for test dependency injection.
       - In `_saveImageStory`:
         - Obtain `final Box<ImageStory> box = widget.imageStoriesBox ?? Hive.box<ImageStory>(StorageConstants.imageStoriesBox);`
         - If `_editingStory == null`:
           - Keep the existing single-mode `AlertDialog` prompt (name TextField, Cancel, Save).
         - If `_editingStory != null`:
           - Open `final result = await showDialog<EditModeSaveResult>(context: context, builder: (context) => EditModeSaveDialog(storyName: _editingStory!.name));`
           - If `result == null`: return without changes (user cancelled).
           - If `result is UpdateExistingStoryResult`:
             - Find the story key in `box`:
               `final key = _editingStory!.key ?? box.keys.firstWhere((k) => box.get(k)?.id == _editingStory!.id);`
             - Create updated story:
               ```dart
               final updatedStory = ImageStory(
                 id: _editingStory!.id,
                 name: _editingStory!.name,
                 images: List<KuvariImage>.from(_selectedImages),
                 tagIds: _editingStory!.tagIds,
               );
               ```
             - `await box.put(key, updatedStory);`
             - Log analytics event:
               ```dart
               await widget.analytics.logEvent(
                 name: 'update_image_story',
                 parameters: {
                   'story_name': updatedStory.name,
                   'image_count': updatedStory.images.length,
                 },
               );
               ```
             - If `context.mounted`: show `SnackBar(content: Text(AppLocalizations.of(context)!.storyUpdated(updatedStory.name)))`.
             - Reset state:
               ```dart
               if (mounted) {
                 setState(() {
                   _editingStory = null;
                   _selectedImages.clear();
                   _currentStartIndex = 0;
                 });
               }
               ```
           - If `result is SaveAsNewStoryResult`:
             - Create new story:
               ```dart
               final newStory = ImageStory(
                 id: const Uuid().v4(),
                 name: result.name,
                 images: List<KuvariImage>.from(_selectedImages),
               );
               ```
             - `await box.add(newStory);`
             - Log analytics event:
               ```dart
               await widget.analytics.logEvent(
                 name: 'save_image_story',
                 parameters: {
                   'story_name': newStory.name,
                   'image_count': newStory.images.length,
                 },
               );
               ```
             - If `context.mounted`: show `SnackBar(content: Text(AppLocalizations.of(context)!.imageStorySaved(newStory.name)))`.
             - Reset state:
               ```dart
               if (mounted) {
                 setState(() {
                   _editingStory = null;
                   _selectedImages.clear();
                   _currentStartIndex = 0;
                 });
               }
               ```
  </action>

  </verify>
  <done>
    HomePage cleanly branches between standard save and edit mode dual save with Hive persistence and state reset.
  </done>
</task>
