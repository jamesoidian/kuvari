# Plan 06.01: Edit on Home Page Transition & Replacement Guard

<objective>
Enable users to open a saved image story for editing on the HomePage (`EDIT-01`), protect against accidental overwrite if the home queue already has items via a confirmation dialog (`EDIT-02`), and transition smoothly into Edit Mode on HomePage with queue population and SnackBar feedback (`EDIT-03`).
</objective>

<task type="auto">
  <name>Task 1: Add localization and edit button with replacement dialog on SavedImageStoriesPage</name>
  <files>
    lib/l10n/intl_fi.arb
    lib/l10n/intl_sv.arb
    lib/l10n/intl_en.arb
    lib/pages/saved_image_stories_page.dart
    test/pages/saved_image_stories_page_test.dart
  </files>
  <action>
    1. Add localized strings in `intl_fi.arb`, `intl_sv.arb`, and `intl_en.arb`:
       - `editOnHomePage`: "Muokkaa kotisivulla" / "Redigera på startsidan" / "Edit on home page"
       - `replaceQueueDialogTitle`: "Korvataanko nykyinen kuvajono?" / "Ersätta nuvarande bildsekvens?" / "Replace current image sequence?"
       - `replaceQueueDialogBody`: "Kotisivulla on jo valittuna {count} kuvaa. Haluatko korvata ne kuvajonon \"{storyName}\" kuvilla?" / "Det finns redan {count} valda bilder på startsidan. Vill du ersätta dem med bilderna från \"{storyName}\"?" / "There are already {count} images selected on the home page. Do you want to replace them with images from \"{storyName}\"?"
       - `replaceAndEdit`: "Korvaa ja muokkaa" / "Ersätt och redigera" / "Replace and edit"
       - `cancel`: "Peruuta" / "Avbryt" / "Cancel" (or reuse existing cancel if present)
       - `editingStoryStarted`: "Muokataan kuvajonoa: {storyName}" / "Redigerar bildsekvens: {storyName}" / "Editing image sequence: {storyName}"
    2. In `SavedImageStoriesPage`:
       - Add optional constructor fields: `final bool hasActiveQueue;` and `final int activeQueueCount;` (default `false` and `0`).
       - In each story card's `ListTile.trailing`:
         - Wrap the play button inside a `Row(mainAxisSize: MainAxisSize.min, children: [...])`.
         - Add an `IconButton(icon: const Icon(Icons.edit_outlined), tooltip: l10n.editOnHomePage, onPressed: () => _handleEditStory(story))`.
         - In `_handleEditStory(ImageStory story)`:
           - If `widget.hasActiveQueue`: show an `AlertDialog` with `replaceQueueDialogTitle`, `replaceQueueDialogBody`, "Peruuta" (`Navigator.pop(dialogContext, false)`), and "Korvaa ja muokkaa" (`Navigator.pop(dialogContext, true)`).
           - If confirmed (or `!widget.hasActiveQueue`): call `Navigator.pop(context, story)` to return the story to the caller.
    3. Update `test/pages/saved_image_stories_page_test.dart`:
       - Verify that `Icons.edit_outlined` is rendered for each story card.
       - Verify that tapping edit with `hasActiveQueue: false` immediately pops with the story.
       - Verify that tapping edit with `hasActiveQueue: true` shows the confirmation dialog, and confirming pops with the story while cancelling keeps the dialog dismissed without popping the page.
  </action>
  <verify>
    flutter test test/pages/saved_image_stories_page_test.dart
  </verify>
  <done>
    Saved story cards display the edit icon button, replacement confirmation dialog guards active home queue, and widget tests pass.
  </done>
</task>

<task type="auto">
  <name>Task 2: Wire transition in HomeAppBar and HomePage with Edit Mode initialization</name>
  <files>
    lib/widgets/home_app_bar.dart
    lib/pages/home_page.dart
    test/pages/home_page_test.dart
  </files>
  <action>
    1. In `HomeAppBar`:
       - Pass `onOpenSavedStories` callback or accept `Function(ImageStory story)? onEditStory` so `HomePage` can manage the transition.
       - Alternatively, when tapping the saved stories list button in `HomeAppBar`, navigate with `await Navigator.push<ImageStory>(context, MaterialPageRoute(builder: (_) => SavedImageStoriesPage(hasActiveQueue: selectedImages.isNotEmpty, activeQueueCount: selectedImages.length)))`.
       - If a non-null `story` is returned, notify `HomePage` (e.g. via an `onEditStory: (story) => ...` callback on `HomeAppBar`).
    2. In `HomePage` (`_HomePageState`):
       - Add `ImageStory? _editingStory;` state variable.
       - Add method `void _startEditingStory(ImageStory story)`:
         - Updates state: `_editingStory = story; _selectedImages = List.from(story.images); _currentStartIndex = 0;`.
         - Shows a SnackBar with `l10n.editingStoryStarted(story.name)`.
    3. In `test/pages/home_page_test.dart`:
       - Test opening and selecting a story for edit sets `_editingStory`, populates `_selectedImages`, and displays the confirmation SnackBar.
       - Ensure all existing home page tests remain green.
  </action>
  <verify>
    flutter test test/pages/home_page_test.dart && flutter test
  </verify>
  <done>
    Tapping edit on a saved story card navigates back to HomePage, populates the queue with the story's symbols, shows the confirmation SnackBar, and passes all tests.
  </done>
</task>
