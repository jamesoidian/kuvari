1. Import `AVFoundation`.
2. Add private properties:
   - `private let speechSynthesizer = AVSpeechSynthesizer()`
   - `private let ttsChannelName = "io.github.jamesoidian.kuvari/tts"`
3. In `application(_:didFinishLaunchingWithOptions:)`:
   - Call `super.application(application, didFinishLaunchingWithOptions: launchOptions)`.
   - Acquire `controller = window?.rootViewController as? FlutterViewController`.
   - Create `FlutterMethodChannel(name: ttsChannelName, binaryMessenger: controller.binaryMessenger)`.
   - Set method call handler handling:
     - `"speak"`:
       - Validate arguments map containing `'text'` as `String`. If missing, return `FlutterError(code: "INVALID_ARGUMENT", message: "text is required", details: nil)`.
       - Extract optional `'language'` as `String` (default `"en-US"`).
       - Extract optional `'rate'` as `NSNumber` / `Float?` and `'pitch'` as `NSNumber` / `Float?`.
       - Invoke private `speak(text:language:rate:pitch:)`.
       - Return `result(nil)`.
     - `"stop"`:
       - Invoke private `stopSpeaking()`.
       - Return `result(nil)`.
     - Default: return `result(FlutterMethodNotImplemented)`.
4. Implement `private func configureAudioSession()`:
   - Set `AVAudioSession.sharedInstance().setCategory(.playback, mode: .spokenAudio, options: [.duckOthers])`.
   - Activate audio session with `setActive(true)`.
   - Wrap in `do-catch` and log errors without crashing.
5. Implement `private func speak(text: String, language: String, rate: Float?, pitch: Float?)`:
   - Call `configureAudioSession()`.
   - If `speechSynthesizer.isSpeaking`, call `speechSynthesizer.stopSpeaking(at: .immediate)` (D-03).
   - Create `AVSpeechUtterance(string: text)`.
   - Resolve BCP-47 locale tag (D-04):
     - `fi`, `fi-fi` -> `fi-FI`
     - `sv`, `se`, `sv-se` -> `sv-SE`
     - `en`, `en-us` -> `en-US`
     - default -> `en-US`
   - Resolve `AVSpeechSynthesisVoice`:
     - Try `AVSpeechSynthesisVoice(language: bcpLocale)`.
     - If nil, fallback to `AVSpeechSynthesisVoice(language: AVSpeechSynthesisVoice.currentLanguageCode())`.
     - If still nil, fallback to `AVSpeechSynthesisVoice(language: "en-US")`.
   - Set rate: `rate ?? AVSpeechUtteranceDefaultSpeechRate` (D-02: natural default ~0.50).
   - Set pitch: `pitch ?? 1.0`.
   - Call `speechSynthesizer.speak(utterance)`.
6. Implement `private func stopSpeaking()`:
   - If `speechSynthesizer.isSpeaking`, call `speechSynthesizer.stopSpeaking(at: .immediate)`.
7. Preserve `didInitializeImplicitFlutterEngine(_ engineBridge: FlutterImplicitEngineBridge)`.

1. Implement `TextToSpeech.OnInitListener` interface on `MainActivity`.
2. Add private properties:
   - `private var tts: TextToSpeech? = null`
   - `private var isTtsInitialized = false`
   - `private var pendingUtterance: Runnable? = null`
   - `private val channelName = "io.github.jamesoidian.kuvari/tts"`
3. In `onCreate(savedInstanceState: Bundle?)`:
   - Keep `enableEdgeToEdge()` and `super.onCreate(savedInstanceState)`.
   - Initialize TTS engine: `tts = TextToSpeech(this, this)`.
4. Implement `override fun onInit(status: Int)`:
   - If `status == TextToSpeech.SUCCESS`:
     - `isTtsInitialized = true`
     - Set default rate: `tts?.setSpeechRate(1.0f)` (D-02).
     - Set default pitch: `tts?.setPitch(1.0f)`.
     - Execute and clear `pendingUtterance?.run(); pendingUtterance = null`.
   - Else: `isTtsInitialized = false; pendingUtterance = null`.
5. Implement `override fun configureFlutterEngine(flutterEngine: FlutterEngine)`:
   - Call `super.configureFlutterEngine(flutterEngine)`.
   - Register `MethodChannel(flutterEngine.dartExecutor.binaryMessenger, channelName).setMethodCallHandler`:
     - `"speak"`:
       - Extract `"text"` as `String? ?: ""`.
       - Extract `"language"` as `String? ?: "en-US"`.
       - Extract `"rate"` as `Double?` converted to `Float ?: 1.0f`.
       - Extract `"pitch"` as `Double?` converted to `Float ?: 1.0f`.
       - If `isTtsInitialized`: call `speakText(text, language, rate, pitch)`.
       - Else: set `pendingUtterance = Runnable { speakText(text, language, rate, pitch) }`.
       - Return `result.success(null)`.
     - `"stop"`:
       - Clear `pendingUtterance = null`.
       - Call `stopSpeaking()`.
       - Return `result.success(null)`.
     - Else: `result.notImplemented()`.
6. Implement `private fun speakText(text: String, language: String, rate: Float, pitch: Float)`:
   - Guard `val ttsEngine = tts ?: return`.
   - Resolve `Locale` from `language`:
     - `fi`, `fi-fi` -> `Locale("fi", "FI")`
     - `sv`, `se`, `sv-se` -> `Locale("sv", "SE")`
     - `en`, `en-us` -> `Locale.US`
     - If contains `"-"`: `Locale(parts[0], parts[1])`
     - Else: `Locale(language)`
   - Set language with fallback protection (D-04):
     - `val langResult = ttsEngine.setLanguage(locale)`
     - If `langResult == TextToSpeech.LANG_MISSING_DATA || langResult == TextToSpeech.LANG_NOT_SUPPORTED`:
       - Try `ttsEngine.setLanguage(Locale.US)`
       - If still missing/unsupported: `ttsEngine.language = Locale.getDefault()`
   - Apply pitch and rate: `ttsEngine.setPitch(pitch); ttsEngine.setSpeechRate(rate)`.
   - Use `QUEUE_FLUSH` to immediately interrupt active speech (D-03):
     - `val utteranceId = "kuvari_${System.currentTimeMillis()}"`
     - `ttsEngine.speak(text, TextToSpeech.QUEUE_FLUSH, null, utteranceId)`.
7. Implement `private fun stopSpeaking()`:
   - Call `tts?.stop()`.
8. Implement `override fun onDestroy()`:
   - Call `tts?.stop()` and `tts?.shutdown()`.
   - Set `tts = null; isTtsInitialized = false; pendingUtterance = null`.
   - Call `super.onDestroy()`.
