  <read_first>lib/services/tts_service.dart, .planning/phases/04-native-text-to-speech-ios-android/04-RESEARCH.md</read_first>
  <action>
Rewrite `lib/services/tts_service.dart`:
1. Remove `import 'package:flutter_tts/flutter_tts.dart';`.
2. Import `package:flutter/foundation.dart';` and `package:flutter/services.dart';`.
3. Add `@visibleForTesting static const MethodChannel defaultChannel = MethodChannel('io.github.jamesoidian.kuvari/tts');`.
4. Add constructor `TtsService({MethodChannel? channel}) : _channel = channel ?? defaultChannel;`.
5. Implement static helper `String normalizeLocale(String languageCode)`:
   - `'fi'`, `'fi-fi'` -> `'fi-FI'`
   - `'sv'`, `'se'`, `'sv-se'` -> `'sv-SE'`
   - `'en'`, `'en-us'` -> `'en-US'`
   - default -> `'en-US'`
6. Implement `Future<void> speak(String text, String languageCode, {double? rate, double? pitch}) async`:
   - Normalize languageCode using `normalizeLocale`.
   - Invoke `_channel.invokeMethod('speak', {'text': text, 'language': locale, if (rate != null) 'rate': rate, if (pitch != null) 'pitch': pitch})`.
   - Wrap in `try-catch` catching `PlatformException`, `MissingPluginException`, and general `Object/Exception`, logging with `debugPrint` without throwing uncaught exceptions.
7. Implement `Future<void> stop() async`:
   - Invoke `_channel.invokeMethod('stop')`.
   - Wrap in `try-catch` catching exceptions safely.
  </action>

  </verify>
