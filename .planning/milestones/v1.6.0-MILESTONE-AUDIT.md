## 1. Executive Summary

Milestone **v1.6.0** introduced safe story browsing and comprehensive editing workflows:
1. **Safe Carousel Browsing:** Accidental reorders and symbol deletions are completely prevented on `SavedImageStoriesPage` by rendering standard non-reorderable lists and suppressing delete overlays.
2. **Transition to Edit Mode:** Users can explicitly open any saved story on `HomePage` in Edit Mode via a dedicated button, protected by queue replacement warning dialogs.
3. **Persistent Edit UI & Protection:** `HomePage` features an amber `EditModeBanner` with live story name editing, quick-save, stop actions, and exit guards against accidental loss of modified stories.
4. **Dual-Mode Save Logic:** When saving an edited story, users can choose between overwriting the existing Hive record (preserving ID and tags) or saving as an independent new story copy (`(kopio)`).

All **9 requirements** across **3 phases** have been completed, verified with empirical evidence and automated tests, and integrated seamlessly end-to-end.

## 3. Cross-Phase Integration & E2E Flows

### 3.1 Story Browsing to Edit Mode Transition (Phase 5 → Phase 6)
- **Flow:** User navigates to `SavedImageStoriesPage` $\rightarrow$ cards render read-only non-reorderable carousels without delete buttons $\rightarrow$ user taps vertically stacked edit icon $\rightarrow$ if home queue has active symbols, warning dialog confirms replacement $\rightarrow$ page pops and returns the `ImageStory` to `HomePage`.
- **Status:** **VERIFIED** via `saved_image_stories_page_test.dart` and `home_page_test.dart`.

### 3.2 Edit Mode Banner & Queue Safeguards (Phase 6)
- **Flow:** `HomePage` receives story $\rightarrow$ populates queue and displays `EditModeBanner` $\rightarrow$ user can add or remove symbols from the queue, or edit the story title inline $\rightarrow$ tapping trash can in carousel prompts clear-confirmation $\rightarrow$ system back navigation / close button prompts discard-confirmation if modified, or exits cleanly if unmodified.
- **Status:** **VERIFIED** via `edit_mode_banner_test.dart` and `home_page_test.dart`.

### 3.3 Dual-Mode Save & Storage Persistence (Phase 6 → Phase 7)
- **Flow:** User taps Save in `EditModeBanner` or `HomeAppBar` $\rightarrow$ `EditModeSaveDialog` presents two distinct cards ("Päivitä" and "Tallenna uutena...") $\rightarrow$
  - If **Päivitä**: updates existing Hive record in place, preserving ID and assigned tag IDs.
  - If **Tallenna uutena...**: prompts with pre-filled name (`[Name] (kopio)`), persists new story under new UUID.
- **Post-condition:** Previous SnackBars cleared, feedback SnackBar shown, edit mode exited, queue cleanly cleared.
- **Status:** **VERIFIED** via `edit_mode_save_dialog_test.dart` and `home_page_test.dart`.

### 3.4 Non-Edit Mode Regression Check
- **Flow:** Standard image searching, symbol collection from empty placeholder, extended FAB navigation to story viewer, and saving new stories when not in edit mode continue to function identically.
- **Status:** **VERIFIED** with 0 regressions across all widget tests.
