<task type="auto">
  <name>Task 2: Implement EditModeSaveDialog widget and result types</name>
  <files>
    lib/widgets/edit_mode_save_dialog.dart
  </files>
  <action>
    Create `lib/widgets/edit_mode_save_dialog.dart`:
    1. Define sealed class `EditModeSaveResult`:
       - `class UpdateExistingStoryResult extends EditModeSaveResult { const UpdateExistingStoryResult(); }`
       - `class SaveAsNewStoryResult extends EditModeSaveResult { final String name; const SaveAsNewStoryResult(this.name); }`
    2. Create `EditModeSaveDialog` (StatefulWidget):
       - Parameter: `final String storyName;`
       - Internal state: `bool _isNamingNew = false;`, `late final TextEditingController _nameController;`
       - In `initState`, initialize `_nameController` with `l10n.storyCopySuffix(widget.storyName)` (or in `didChangeDependencies`).
       - If `!_isNamingNew`:
         - Title: `Text(l10n.saveImageStory)`
         - Content: `Column(mainAxisSize: MainAxisSize.min, children: [...])`:
           - Option 1 (Card/ListTile):
             - Leading: `Icon(Icons.update, color: Colors.teal, size: 28)`
             - Title: `Text(l10n.updateExistingStory(widget.storyName), style: TextStyle(fontWeight: FontWeight.bold))`
             - Subtitle: `Text(l10n.updateExistingStoryDescription)`
             - On tap: `Navigator.of(context).pop(const UpdateExistingStoryResult());`
           - Option 2 (Card/ListTile):
             - Leading: `Icon(Icons.bookmark_add_outlined, color: Colors.teal, size: 28)`
             - Title: `Text(l10n.saveAsNewStory, style: TextStyle(fontWeight: FontWeight.bold))`
             - Subtitle: `Text(l10n.saveAsNewStoryDescription)`
             - On tap: `setState(() => _isNamingNew = true);`
         - Actions:
           - `TextButton(onPressed: () => Navigator.of(context).pop(null), child: Text(l10n.cancel))`
       - If `_isNamingNew`:
         - Title: `Text(l10n.saveAsNewStoryTitle)`
         - Content: `TextField` with `_nameController`, autofocus, `labelText: l10n.giveImageStoryName`.
         - Actions:
           - `TextButton(onPressed: () => setState(() => _isNamingNew = false), child: Text(l10n.back))`
           - `ElevatedButton(onPressed: _nameController.text.trim().isEmpty ? null : () => Navigator.of(context).pop(SaveAsNewStoryResult(_nameController.text.trim())), child: Text(l10n.save))`
  </action>
  <verify>
    flutter test test/smoke_test.dart
  </verify>
  <done>
    EditModeSaveDialog provides seamless two-state navigation between action choices and name input.
  </done>
</task>
