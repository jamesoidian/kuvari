<task type="auto">
  <name>Task 2: Integrate EditModeBanner and data loss protection guards into HomePage</name>
  <files>
    lib/pages/home_page.dart

  </files>
  <action>
    1. In `lib/pages/home_page.dart`:
       - Above `AnimatedCrossFade`, conditionally render `EditModeBanner(storyName: _editingStory!.name, onSave: _onSaveEditStory, onStop: _promptExitEditMode)` when `_editingStory != null`.
       - Add a helper `bool get _isStoryModified`:
         - Returns `true` if `_editingStory == null` (not applicable), or if `_selectedImages.length != _editingStory!.images.length`, or if image ids/uids at any index differ from `_editingStory!.images`.
       - Guard clear queue in `_clearSelectedImages()`:
         - If `_editingStory != null`: show confirmation dialog (`clearQueueDialogTitle`, `clearQueueDialogBody`, cancel, confirm). Only clear if confirmed.
         - If `_editingStory == null`: clear immediately as before.
       - Implement `_promptExitEditMode()`:
         - If `_isStoryModified`: show confirmation dialog (`discardChangesDialogTitle`, `discardChangesDialogBody`, cancel, discard). If discarded, set `_editingStory = null; _selectedImages.clear();`.
         - If not modified: immediately set `_editingStory = null; _selectedImages.clear();`.
       - Update `PopScope`:
         - Guard back navigation when in edit mode with unsaved changes. Prompt discard dialog before allowing pop.
       - In `_onSaveEditStory`: for Phase 6, stub or invoke save flow (full dual-mode save dialog implemented in Phase 7).
    2. In `test/pages/home_page_test.dart`:
       - Test that `EditModeBanner` is displayed when in edit mode.
       - Test that tapping clear in edit mode prompts confirmation dialog.
       - Test that exiting edit mode with modifications prompts discard dialog.
       - Test that exiting edit mode without modifications exits immediately.
       - Run full test suite to ensure all tests pass.
  </action>

  </verify>
